# **App Name**: PopUp Forge

## Core Features:

- Message Input: Input field for the notification message.
- Display Delay: Slider to set the display delay.
- Preview Pop-up: A button to generate the popup.
- Pop-up Preview: Simulated pop-up display for previewing, with 'Close' functionality.
- Configuration Export: Export configuration, for use on the user's website.

## Style Guidelines:

- Primary color: Teal (#008080) for a modern feel. Note: per your request.
- Background color: Light gray (#E0E0E0) for a clean interface.
- Accent color: A lighter shade of teal (#4DB6AC) for interactive elements to ensure visibility against the background.
- Font: 'Inter' (sans-serif) for a modern and readable interface; for both headlines and body.
- Clean, well-spaced layout with clear visual hierarchy.
- Subtle fade-in animation for the pop-up to smoothly introduce it.
